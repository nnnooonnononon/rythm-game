🦭 Rhythm Tap

เกมฝึกอ่านจังหวะ (Rhythm Sight-reading) — ดูโน้ตบนบรรทัด 5 เส้น แล้วตบให้ตรงกับเมโทรนอม พร้อมน้องแมวน้ำตีพุงเป็นจังหวะ

ตัวเลือกเพิ่มเติม
กด “เริ่ม” แล้วตบตามจังหวะเมโทรนอม
♩ = 70
เป๊ะ 0 ดี 0 พอใช้ 0 พลาด 0 ตบเกิน 0
น้องแมวน้ำตีพุง

วิธีเล่น

  • โน้ตทุกตัวอยู่บนเส้นกลางของบรรทัด (กุญแจเพอร์คัสชัน) — ดูแค่ “ความยาว” ของตัวโน้ตและตัวหยุด
  • กด เริ่ม จะมีนับเข้า 1 ห้อง แล้วเส้นสีส้มจะวิ่งไปตามโน้ต ให้ตบตรงตัวโน้ต ส่วนตัวหยุด (rest) ไม่ต้องตบ
  • ตบได้ด้วยปุ่มใหญ่ (แตะหน้าจอ) หรือคีย์บอร์ด Space / F / J
  • เทียบความยาวใน 1 จังหวะ: ตัวกลม = 4 · ตัวขาว = 2 · ตัวดำ = 1 · เขบ็ตชั้นเดียว = ½ · เขบ็ตสองชั้น = ¼ · จุดต่อท้ายเพิ่มอีกครึ่งหนึ่ง · ตริโอเล็ต = 3 ตัวใน 1 จังหวะ
  • น้องแมวน้ำจะตีพุงตามที่คุณตบ (ตบแม่นจะยิ้ม ตบพลาดจะเหงื่อตก) และในโหมด “ฟังตัวอย่าง” น้องจะตีพุงเล่นจังหวะให้ดู
  • หลังจบรอบ ตัวเลขใต้โน้ตแสดงว่าตบเร็ว (−) หรือช้า (+) กี่มิลลิวินาที ใช้หูฟังจะแม่นกว่าลำโพง
